How to Test Token Sync

  1. Make sure you're logged into the web app at https://automatorx.co
  2. Click "Test Chrome APIs" to verify extension permissions
  3. Click "Test Web App Connection" to check if the web app is accessible
  4. Click "Get User ID from Web App" to test communication with the web app
  5. Click "Check Authentication" to test the token sync flow
  6. If tests fail, try "Force Refresh Auth" to clear cached data and retry
  7. Use "Run All Tests" for a comprehensive test suite
