Upload Fix Test

Problem

Issue: When user clicks upload button and they are NOT on TikTok upload page, the extension opens "https://www.tiktok.com/tiktokstudio/upload" but does NOT automatically upload the video. User needs to click again.

Solution Implemented

Fixed in popup.js:
  1. Enhanced handleUploadClick() function:
    • Added waitForContentScriptReady() function that checks if content script is loaded before sending upload message
    • Added sendUploadMessageWithRetry() function with exponential backoff retry logic (up to 3 retries)
    • Added PING message handling to verify content script is ready
  2. Updated content.js:
    • Added handler for PING action to respond when content script is ready

Key Code Changes

// New function in popup.js function waitForContentScriptReady(tabId) { return new Promise((resolve) => { const maxAttempts = 10; let attempts = 0; const checkContentScript = () => { attempts++; console.log(`Checking if content script is ready (attempt ${attempts}/${maxAttempts})...`); chrome.tabs.sendMessage(tabId, { action: "PING" }, (response) => { if (chrome.runtime.lastError) { if (attempts >= maxAttempts) { console.log("Content script not ready after max attempts, proceeding anyway..."); resolve(); return; } // Content script not ready yet, wait and retry setTimeout(checkContentScript, 1000); } else { console.log("Content script is ready!"); resolve(); } }); }; // Start checking after a short delay setTimeout(checkContentScript, 2000); }); } // New function in popup.js async function sendUploadMessageWithRetry(tabId, video) { const maxRetries = 3; let retryCount = 0; const sendMessage = () => { return new Promise((resolve, reject) => { chrome.tabs.sendMessage( tabId, { action: "UPLOAD_VIDEO", data: { taskId: video.id, videoUrl: video.complete_video || video.video_url, caption: video.tone || `${video.title} - ${video.price}`, }, }, (response) => { if (chrome.runtime.lastError) { const error = chrome.runtime.lastError; console.error("Error sending message:", error); // Check if content script is not ready if (error.message.includes("Receiving end does not exist")) { reject(new Error("Content script not ready")); } else { reject(error); } } else if (response && !response.success) { console.error("Upload failed:", response.error); reject(new Error(response.error)); } else { console.log("Video upload started successfully."); resolve(response); } } ); }); }; // Try to send the message with retries while (retryCount < maxRetries) { try { await sendMessage(); return; // Success } catch (error) { retryCount++; console.log(`Upload attempt ${retryCount} failed:`, error.message); if (retryCount >= maxRetries) { console.error("Max retries reached, upload failed."); alert(`Failed to upload video after ${maxRetries} attempts. Please try again.`); return; } // Wait before retrying const waitTime = retryCount * 2000; // Exponential backoff: 2s, 4s, 6s console.log(`Waiting ${waitTime}ms before retry ${retryCount + 1}...`); await new Promise(resolve => setTimeout(resolve, waitTime)); } } }

Expected Behavior

When user clicks upload button:
  1. If user is already on TikTok upload page:
    • Extension finds the existing tab
    • Sends UPLOAD_VIDEO message immediately
    • Video upload starts automatically
  2. If user is NOT on TikTok upload page:
    • Extension opens "https://www.tiktok.com/tiktokstudio/upload" in new tab
    • Waits 2 seconds for page to load
    • Checks if content script is ready (sends PING message)
    • If content script responds, sends UPLOAD_VIDEO message
    • If content script doesn't respond, waits and retries up to 10 times
    • Once content script is ready, sends upload message with retry logic
    • Video upload starts automatically
